# Шумоподавляющий автокодировщик (OrganSMNIST)

**Задача.** Восстановить чистое изображение из зашумлённого (гауссовский шум, σ = 0.1 в диапазоне [-1, 1]).
**Данные.** [OrganSMNIST](https://medmnist.com) (MedMNIST), 28×28, 1 канал. Скачивается автоматически (`pip install medmnist`).
**Модель.** Encoder: 2 × (Conv + BatchNorm + ReLU) до 64×7×7. Decoder: 2 × ConvTranspose2d, выход `Tanh`. Loss: MSE, оптимизатор Adam.

## Как оценивается
Главная метрика: **MSE после модели против MSE самого зашумлённого входа** (базовый уровень). Если модель не лучше базового уровня, она не денойзит. Ячейка с тестом печатает это сравнение.

## Ограничения
- Шум одного типа и одной силы (гауссовский, σ = 0.1).
- Нет PSNR/SSIM и сравнения с классическими фильтрами (медианный, гауссов), и это логичное продолжение.
