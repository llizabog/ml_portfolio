# Transfer learning: яблоки vs апельсины

**Задача.** Бинарная классификация на собственном датасете (74 изображения train / 60 test).
**Модель.** ResNet-18 из `timm`, предобученная на ImageNet.
**Данные.** Фото из интернета. Структура: `train/apple`, `train/orange`, `test/apple`, `test/orange`; архив `data.zip` распаковывается в `/content`.

## Результаты
| Подход | Train acc | Test acc |
|---|---|---|
| Feature extraction | ~94% | **67.8%** (40/59) |
| Fine-tuning (все веса, lr = 1e-4) | ~99% | **71.2%** (42/59)|

## Вывод и ограничения
- Большой разрыв train/test показывает переобучение на 72 картинках, а на двух примерах «модель угадала» надёжность не оценить.
- Тест маленький (59), поэтому одна картинка меняет точность на ~1.7 п.п. Нужны больше данных, кросс-валидация и confusion matrix.
- Нет отдельной валидационной выборки: выбор приёма делался по тесту, и это завышает оценку.
